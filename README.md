# 🎓 Student Attendance App UI Design – High-Fidelity

## ✨ Project Overview

This is a **Student Attendance App High-Fidelity UI Design** created using Figma. The application provides a modern and attractive interface for students and teachers to manage attendance, view attendance records, check attendance percentage, and monitor daily attendance.

## 🎯 Objective

The main objective of this project is to design a **user-friendly Student Attendance application** with a clean, modern, and visually appealing interface that makes attendance management simple, quick, and convenient.
